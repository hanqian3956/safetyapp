移动端预警任务 · 功能说明

1页签（按当前登录人与该预警的关系）
未处理 / 通知我 / 已处理 / 我转发。仅「未处理」「通知我」带数量角标，数量为当前登录人在该页签下的待办条数，实时计算。同一预警可在本人多个页签同时出现（身份不同）；作废预警不出现在任何页签。
2查询与筛选
等级快捷筛选：全部等级 / 未分级 / 一级 / 二级 / 三级 / 四级，精确匹配；「未分级」只返回规则未指定等级的预警。点右上「筛选」叠加：时间维度（触发时间 / 处理期限）+ 起止日期（自然日闭区间，含当日 00:00—23:59）+ 预警工作项（包含匹配）。查询只作用于当前页签；「重置」清空全部条件（时间维度回「触发时间」、日期为空、工作项为空、等级回「全部等级」）并重查当前页签。
3预警卡片
标题 = 预警内容（规则里配的条件组名称）；编号 WRN-YYYYMMDD-NNN。风险等级颜色固定：一级红、二级橙、三级蓝、四级绿，规则未指定显示灰色「未分级」。处理人取首人 + 「等 N 人」，仅 1 人不显示徽标；处理期限只显示时间，不标红、不写状态文字，是否超期由徽标单独表达。列表按触发时间倒序。
4命中明细（点「预警工作项」展开）
展开在本卡片内，不新开弹窗：工作项 / 判定 / 预警值（阈值）/ 触发值（实测，红色加粗）。命中 1 项与多项交互完全一致；无命中数据时工作项显示「—」。
5状态与超期（两个独立维度）
状态按「已提交处置人数 / 处理人总数」计算：0 → 未处理，部分 → 处理中，全部 → 已完成；仅 1 个处理人时不会出现「处理中」；作废不属于任务状态。超期徽标按当前登录人个人判定、不看整条任务：本人未提交且已过期 →「已超期」；本人已提交且提交时间晚于期限 →「超期完成」；按期完成或未到期不显示。
6处理人明细（点「处理人」进入）
只列人、不带日志，用于核对「谁在办、办了没、几点交的」：姓名 / 来源角色类别 / 处置状态 / 提交时间 / 处理详情。顶部显示派单快照时间——处理人触发时解析并固化，组织架构后续变动不影响本条。解析不到人员的预警属「分派异常」，不进任何页签，只在 PC 端「预警信息表统计」由企业管理员指派。

详情三种模式（同一套内容，按入口切换）

7处理（编辑）
仅「未处理」页签的「处理」进入。内容：基础信息（处理人只读显示全部）+ 命中明细 + 本人处置填写 + 处理日志。不显示处理人列表，不暴露他人处置进度。页脚「取消 / 提交处置」。
8任务详情（只读）
点卡片或「查看」进入。基础信息 + 命中明细 + 处理人列表 + 处理日志，无处置区，页脚只有「关闭」。
9个人处置详情（只读）
从处理人明细点「查看」进入。只展示该处理人的处置内容（处理情况 / 附件 / 电子签字 / 提交时间），不含处理人列表、不含日志，页脚「返回」回到上一层。已提交内容不可编辑、不可重新提交。

填写与提交

10处理情况 / 附件 / 签字
处理情况必填、≤500 字、trim 后非空，提交后不可修改；整改照片/附件选填、≤9 个、单个 ≤10MB、限 jpg/jpeg/png/pdf，提交后不可删除；实际处理人与实际处理时间只读，由服务端在提交时写入，未提交显示「提交处置时自动记录」；电子签字必填，未签不可提交。
11转发规则
仅「未处理」且当前登录人是处理人时可转发；从组织架构选一名具体人员、不能选自己；转办说明选填 ≤200 字。单条预警只允许转发 1 次，转发后按钮消失，原处理人退出该任务并在「我转发」页签留痕，写入一条「转发预警」日志。
12处理日志
日志是任务级的，只出现在「处理」与「任务详情」两处，「个人处置详情」不重复出现。默认收起，点标题行展开；按时间正序，记录触发 / 处理 / 转发 / 调整处理人 / 作废五类节点，含操作人及其角色，只读不可删改。
13提交流转
提交后本人处置状态置为已处理并写入提交时间；全部处理人已提交 → 任务转「已完成」并从待办消失，部分提交则任务转「处理中」仍留在「未处理」。提交按钮点击后置灰防重，同一处理人同一预警幂等。

样式规范

主色 #0F6CBD（选中 / 主按钮）· 危险 #F5655B（预警 / 超期 / 未处理）· 警示 #E6A23C（处理中 / 超期完成）· 成功 #2BA471（已完成）。字体 Segoe UI Variable Text / Noto Sans SC。圆角：卡片 12 / 按钮 8-10 / 弹层 16。
